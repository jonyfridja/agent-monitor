Choose the password your phone will use to open the dashboard. Phones can't connect until one is set.

    Connect your agents

    agent-monitor learns what your agents are doing through hooks: a small curl entry per event in the agent's config file. Nothing is added unless you click Install hooks. A backup of the file is made first, and Uninstall (here or in the main window) removes only these entries.

    Restart agent sessions that are already running — hooks are read when a session starts.
